# VK Music Exporter

Бесплатное расширение для сохранения **«Моей музыки» и плейлистов ВК в CSV**. Откройте список, дождитесь загрузки песен и скачайте таблицу с исполнителями и названиями.

**Дополнительные аккаунты, подписки и ключи API не нужны.** Расширение работает на странице ВК, в которую вы уже вошли. Аудиофайлы не скачиваются. Прямого переноса в Spotify нет.

## Скачать и установить

1. На странице репозитория нажмите **Code → Download ZIP**.
2. Распакуйте архив в постоянную папку. Не удаляйте и не перемещайте её после установки.
3. В Яндекс Браузере откройте `browser://extensions`. В Chrome — `chrome://extensions`, в Edge — `edge://extensions`.
4. Включите **«Режим разработчика»**, нажмите **«Загрузить распакованное расширение»**.
5. Выберите папку **`browser-extension`**, внутри которой находится `manifest.json`.

Проверено пользователем в Яндекс Браузере. Используются API расширений Chromium; работу в Chrome и Edge отдельно ещё не проверяли. Firefox пока не поддерживается. В магазине расширений приложение пока не опубликовано.

## Как пользоваться

1. Откройте в ВК «Мою музыку» или один плейлист. Если в поиске введён запрос, очистите его.
2. Нажмите значок расширения и задайте имя файла.
3. **Прокрутите список в самый низ.** Листайте медленно и ждите подгрузки песен.
4. Нажмите **«Выбрать список на странице»**, затем нажмите на любую песню в нужном списке. В панели появится количество найденных песен.
5. Нажмите **«Скачать CSV»**. Файл появится в загрузках браузера или браузер предложит выбрать папку.
6. Для следующего списка сначала сохраните текущий файл, затем нажмите **«Очистить сбор и выбрать другой список»** под кнопкой скачивания.

Если ВК удаляет уже просмотренные строки со страницы, после предварительной прокрутки могут найтись только последние песни. В таком случае очистите сбор, вернитесь к первой песне, выберите список и прокрутите вниз ещё раз. Проверьте количество, начало и конец результата.

## Что сохраняется

CSV в UTF-8 с BOM: позиция, исполнитель, название, альбом, длительность, ID трека, ссылка и статус доступности. Неизвестные значения остаются пустыми. В новой разметке ВК длительность намеренно не определяется, чтобы не перепутать её с временем воспроизведения. Текстовые поля защищаются от выполнения формул при открытии в таблицах.

Собранный порядок и повторные вхождения сохраняются. Полнота экспорта автоматически **не гарантируется**: ВК подгружает песни и может менять разметку. При обнаруженном разрыве сбор останавливается; неоднозначные повторы требуют ручной проверки. CSV — таблица, а не доказательство полного совпадения с источником.

В раскрывающихся разделах панели доступны проверка количества, JSON с отчётом и диагностика. Крестик скрывает панель; обновление или закрытие вкладки удаляет несохранённый сбор.

## Приватность и разрешения

Расширение не запрашивает пароли, cookies или токены, не содержит собственного сервера и не отправляет списки на сторонние сервисы. Разрешения: `activeTab` — доступ к выбранной вкладке после нажатия значка; `scripting` — запуск сборщика на странице ВК. Подробнее: **[PRIVACY.md](PRIVACY.md)**.

## Разработка

Зависимости для работы расширения не нужны. Для проверок нужен Node.js с поддержкой Unicode property escapes:

```sh
node browser-extension/verify.cjs
node browser-extension/verify-panel.cjs
```

Тесты проверяют сбор последовательностей, CSV, имена файлов и действия панели на моделируемых данных. Визуальную проверку и проверку актуальной страницы ВК выполняйте в браузере. После изменения файлов обновите расширение круговой стрелкой, затем перезагрузите вкладку ВК.
