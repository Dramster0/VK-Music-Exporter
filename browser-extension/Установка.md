# Как сохранить музыку ВК в CSV

Расширение сохраняет таблицу с названиями песен и исполнителями из «Моей музыки» или одного плейлиста. Аудиофайлы оно не скачивает. Дополнительные подключения и входы не нужны: достаточно открыть музыку в уже используемом аккаунте ВК. Прямого переноса в Spotify нет.

## Установка в Яндекс Браузере

1. Откройте `browser://extensions` в адресной строке браузера.
2. Включите «Режим разработчика» и нажмите «Загрузить распакованное расширение».
3. Выберите папку `browser-extension`, в которой лежит файл `manifest.json`. В окне выбора файлы могут быть скрыты: выбирается сама папка.
4. Найдите VK Music Exporter в меню расширений браузера. При желании закрепите его значок рядом с адресной строкой.

В Chrome используется адрес `chrome://extensions`, в Edge — `edge://extensions`.

**Если расширение уже установлено:** нажмите круговую стрелку на его карточке, затем обновите вкладку ВК. Повторно устанавливать папку не нужно. Перед обновлением скачайте текущий результат: перезагрузка вкладки его удалит.

## Как сохранить список и скачать следующий

1. **Откройте нужный список в ВК.** Перейдите в «Мою музыку» или откройте один плейлист. Если вы уже листали песни, вернитесь к первой. Если искали песню через поиск, очистите поле поиска. Так в файл попадёт весь список, а не только результаты поиска.
2. **Нажмите значок расширения и задайте название файла.** Например, «Музыка для дороги». Получится `Музыка для дороги.csv`. Если поле пустое — `Музыка ВК.csv`. Недопустимые для Windows символы заменяются автоматически.
3. **Прокрутите список в самый низ.** Листайте медленно, понемногу. Если новые песни ещё загружаются, подождите и продолжайте. Число собранных треков будет расти. Пока идёт сбор, оставайтесь в этом списке.
4. **Выберите список.** Нажмите «Выбрать список на странице», затем нажмите на любую песню в нужном списке. В панели появится количество найденных песен.
5. **Дойдите до последней песни и нажмите «Скачать CSV».** Браузер сохранит файл в загрузки или предложит выбрать папку. Если файл с таким именем уже есть, браузер может добавить к имени номер.
6. **Хотите скачать ещё один CSV?** Сначала сохраните текущий файл. Нажмите **«Очистить сбор и выбрать другой список»** под кнопкой **«Скачать CSV»**. Затем откройте нужный список ВК и повторите шаги 2–5.

Крестик скрывает панель и сохраняет сбор в памяти вкладки. Нажмите значок расширения ещё раз, чтобы вернуть панель. Закрытие или обновление вкладки удаляет несохранённый сбор.

Если после выбора нашлись только последние песни, ВК мог скрыть начало списка. Тогда очистите сбор, вернитесь к первой песне, выберите список и прокрутите вниз ещё раз. Скачивание после предварительной прокрутки не гарантирует полноту на всех страницах ВК.

## Ещё один плейлист

Сначала скачайте текущий результат. Нажмите «Очистить сбор и выбрать другой список» под кнопкой «Скачать CSV». Перейдите к новому плейлисту и повторите шаги выше.

## Проверка полноты

Откройте «Проверить, всё ли собрано». Если ВК показывает точное количество песен именно в выбранном списке, введите его. Значения вроде «1,3 тыс.» не подходят. Если счётчика в ВК нет, оставьте поле пустым. Не вводите число из расширения — сравнение тогда ничего не проверяет.

Отметьте начало и конец списка, если действительно проверили их, и нажмите «Сверить список». После появления новых песен подтверждение конца сбрасывается. Даже совпадение числа не гарантирует отсутствие всех ошибок. Без независимой проверки полнота остаётся неподтверждённой.

В CSV находится только таблица. Для сохранения отчёта проверки дополнительно скачайте JSON в разделе помощи. В JSON сохраняется список вместе с отчётом проверки.

## Если что-то пошло не так

- **Видна только одна песня:** убедитесь, что выбрали песню внутри списка, а не верхний плеер. Если проблема повторяется, сохраните диагностику.
- **Счётчик перестал расти:** подождите подгрузки ВК. Если появились новые песни, а счётчик не изменился, результат может быть неполным.
- **Сбор остановился:** скачайте частичный результат. Для нового сбора очистите его, вернитесь к верху списка и прокручивайте медленнее.
- **Excel показывает одну колонку:** выберите «Из текста/CSV», кодировку UTF-8 и разделитель «запятая».
- **Нужна диагностика:** в разделе помощи нажмите «Скачать диагностику трека», затем название проблемной песни. Файл `vk-layout-diagnostic.json` содержит структуру элементов без текста страницы, ссылок, значений атрибутов и cookies. Его можно передать разработчику. Пароли и токены не нужны.

## Ограничения

Сбор работает по загруженным элементам страницы ВК. Разметка сайта может меняться. Начало и конец автоматически не определяются; автоматической прокрутки и восстановления после закрытия вкладки пока нет. Длительность в новой разметке оставлена пустой, чтобы не перепутать её с временем воспроизведения. Порядок собирается по перекрывающимся порциям строк; при разрыве сбор останавливается. Повторяющиеся последовательности песен могут требовать ручной сверки.
